# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## Проект

Платформа динамических опросов студентов с AI-интервьюером (учебный проект ГУАП). Главный источник требований — техническое задание (ТЗ); ссылки на его пункты вида «п. 4.5.2 ТЗ» встречаются в коде. Общение, комментарии в коде, docstring, README и сообщения коммитов — на русском языке. Имена в коде — на английском.

## Команды

```bash
# Сервер (из backend/)
uv sync                       # зависимости
uv run uvicorn app.main:app --reload
uv run pytest                 # тесты
uv run ruff check . && uv run ruff format --check .

# Клиент (из frontend/)
npm install
npm run dev
npm run lint && npm run build

# Инфраструктура (из корня)
docker compose up -d db redis
```

Перед тем как считать задачу готовой, прогоните тесты и линтеры той части, которую меняли.

## Архитектура

- `backend/app/llm/` — все обращения к LLM только через `LLMProvider` (`base.py`); модуль выбирается в `registry.py` по настройкам, в том числе отдельно для задачи (`LLMTask`). Не вызывайте SDK моделей напрямую из других модулей.
- `backend/app/interview/` — движок интервью. Состояние (текущая тема, число уточнений, покрытые темы) хранится в коде; модель только предлагает следующий шаг в JSON, решение принимает код.
- `backend/app/privacy/` — обезличивание: regex → Natasha NER + список имён → LLM.
- `backend/app/analysis/` — фасеты, кодбук, кластеризация, порог k, цитаты.
- `backend/app/devmode/` — MCP-сервер режима разработки.
- `backend/prompts/` — промпты отдельно от кода, с версией в имени файла.
- `frontend/` — React + Vite + TypeScript, графики на Apache ECharts.

## Обязательные правила

1. **ПДн и 152-ФЗ.** В Claude API (и любые зарубежные сервисы) передаются только тексты после обезличивания. Сырые ответы хранятся только в БД `identity`. В БД `analytics` нет идентификаторов пользователей.
2. **Не логировать тексты ответов респондентов.** В логах только идентификаторы и коды ошибок.
3. **Ответы LLM — только JSON по Pydantic-схеме**, с проверкой и не более двух повторов при ошибке.
4. **Числа на дашборде считает БД** (SQL), не модель. Темы с числом уникальных респондентов меньше k уходят в «Прочее» без цитат.
5. **Цитаты** показываются, только если дословно найдены в обезличенном диалоге.
6. **Кризисный сценарий** (признаки кризисного состояния респондента) решает код, а не LLM.
7. **Режим разработки** (`DEV_MODE=true`, `McpDevProvider`) — только синтетические и тестовые данные. Реальные ответы студентов не используются ни в тестах, ни в фикстурах, ни в промптах.
8. **Секреты** только в `.env` (он в `.gitignore`). Новые параметры добавляйте в `app/config.py` и `.env.example`.
9. Интервьюер задаёт не больше одного вопроса за реплику и не утверждает фактов о курсе вне переданного контекста.

## Стиль

- Python 3.11+, типизация везде, ruff (line-length 100). Pydantic-модели для всех данных на границах.
- Новый модуль LLM: наследник `LLMProvider` в `app/llm/providers/`, ветка в `registry.py`, тест с `FakeProvider` или моками без сети.
- Тесты не ходят в сеть и не требуют ключей API.
- Коммиты небольшие, сообщение по-русски в повелительном наклонении: «Добавить модуль GigaChat».
