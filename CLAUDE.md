# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## Проект

Платформа динамических опросов студентов с AI-интервьюером (учебный проект ГУАП). Главный источник требований — техническое задание (ТЗ); ссылки вида «п. 4.5.2 ТЗ» встречаются в коде. Команда — студенты первого курса, поэтому код должен быть простым и понятным: без лишних абстракций, с короткими комментариями на русском. Общение, комментарии, README и сообщения коммитов — на русском, имена в коде — на английском.

## Команды

```bash
# Сервер (из backend/)
uv sync
uv run uvicorn app.main:app --reload
uv run pytest
uv run ruff check . && uv run ruff format --check .

# Клиент (из frontend/)
npm install
npm run dev
npm run lint && npm run build

# Инфраструктура (из корня)
docker compose up -d db redis
```

Перед тем как считать задачу готовой, прогоните тесты и линтеры той части, которую меняли.

## Архитектура

- `backend/app/llm/` — к модели обращаемся только через `LLMProvider` (`base.py`), модуль создаёт `get_provider()` по настройке `LLM_PROVIDER`. Новая модель — новый класс в `providers/` и ветка в `get_provider()`.
- `backend/app/interview/`, `privacy/`, `analysis/` — пока пустые, в docstring описано, что там будет.
- `backend/prompts/` — промпты отдельно от кода, версия в имени файла.
- `frontend/` — React + Vite + TypeScript.

## Обязательные правила

1. **ПДн и 152-ФЗ.** В Claude API и другие зарубежные сервисы передаются только тексты после обезличивания. Сырые ответы хранятся только в БД `identity`, в БД `analytics` нет идентификаторов пользователей.
2. **Не логировать тексты ответов респондентов.**
3. **Ответы LLM — только JSON по Pydantic-схеме**, с проверкой и не более двух повторов при ошибке.
4. **Числа на дашборде считает БД**, а не модель. Темы, упомянутые меньше чем k респондентами, не показываются отдельно.
5. **Секреты** только в `.env`. Новые параметры добавляйте в `app/config.py` и `.env.example`.
6. В тестах и примерах только синтетические данные, тесты не ходят в сеть.
7. Новые библиотеки добавляем, только когда они реально нужны в коде.

Коммиты небольшие, сообщение в повелительном наклонении: «Добавить модуль GigaChat».
