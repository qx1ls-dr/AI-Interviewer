# AI-интервьюер

Платформа динамических опросов студентов с AI-интервьюером. Заменяет обычные веб-анкеты (Google Forms и т.п.): вместо фиксированного списка вопросов языковая модель ведёт короткое интервью в чате и задаёт уточняющие вопросы. После закрытия опроса платформа удаляет из диалогов персональные данные, группирует проблемы и предложения по темам и показывает организатору дашборд с выводами и цитатами.

Учебный проект команды группы 4618 ГУАП, осенний семестр 2026/2027. Требования описаны в техническом задании (ТЗ).

> Сейчас в репозитории только каркас: структура папок, запуск сервера и клиента, база данных в Docker и CI. Функции добавляются по этапам ТЗ.

## Стек

- **Сервер:** Python 3.11+, FastAPI, Pydantic
- **Клиент:** TypeScript, React, Vite
- **Данные:** PostgreSQL 16 + pgvector (две БД: `identity` и `analytics`), Redis
- **Тесты и качество:** pytest, ruff, ESLint, GitHub Actions
- **Развёртывание:** Docker Compose

Библиотеки для следующих этапов (SQLAlchemy, RQ, Natasha, sentence-transformers, графики для дашборда) добавляем, когда до них доходит работа.

## Работа с моделями

Код обращается к модели только через интерфейс `LLMProvider` ([backend/app/llm/base.py](backend/app/llm/base.py)). Модель выбирается в `.env` параметром `LLM_PROVIDER`:

| Значение | Модуль | Когда использовать |
|---|---|---|
| `gigachat` | GigaChat API через библиотеку `gigachat` | основная модель на старте, бесплатный тариф |
| `claude_code` | Claude по подписке через Claude Code | разработка и отладка промптов на синтетических данных |
| `fake` | заглушка | автотесты |

Оба модуля отвечают JSON по схеме: если модель ошиблась, запрос повторяется не больше двух раз.

**GigaChat.** Получите ключ авторизации в [личном кабинете](https://developers.sber.ru/studio) и впишите в `GIGACHAT_CREDENTIALS`. Если появляется ошибка SSL, установите сертификат Минцифры или на время разработки поставьте `GIGACHAT_VERIFY_SSL=false`.

**Claude по подписке.** Модуль вызывает Claude Code в неинтерактивном режиме (`claude -p`), поэтому тратится подписка Claude Pro/Max, а не платный API. Установите [Claude Code](https://docs.claude.com/en/docs/claude-code), один раз запустите `claude` и войдите в аккаунт. Ограничения (п. 4.5.3 ТЗ):
- только синтетические и тестовые данные, реальные ответы студентов сюда не отправляем;
- при `APP_ENV=production` модуль не запускается;
- работает там, где установлен Claude Code, то есть на компьютере разработчика, а не в Docker.

Позже по тому же образцу добавятся модуль Claude API и YandexGPT. В Claude API можно будет отправлять только тексты, из которых уже удалены персональные данные (152-ФЗ).

## Быстрый старт

Нужны Docker, [uv](https://docs.astral.sh/uv/) и Node.js 22.

```bash
cp .env.example .env
docker compose up -d db redis   # PostgreSQL и Redis

cd backend
uv sync
uv run uvicorn app.main:app --reload
# http://localhost:8000/api/health, документация API: http://localhost:8000/docs
```

Во втором терминале:

```bash
cd frontend
npm install
npm run dev                     # http://localhost:5173
```

Тесты и проверки (их же запускает CI):

```bash
cd backend && uv run pytest && uv run ruff check . && uv run ruff format --check .
cd frontend && npm run lint && npm run build
```

## Как вносить изменения

- Работаем в отдельных ветках и через pull request в `main`.
- Перед PR прогоните тесты и линтеры.
- Ключи API только в `.env`. Реальные ответы студентов, выгрузки и дампы БД в репозиторий не кладём.
