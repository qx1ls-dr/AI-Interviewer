# Промпты

Промпты хранятся отдельно от кода (п. 4.5.2 ТЗ), версия в имени файла: `interviewer/v1.md`, `interviewer/v2.md` и т.д. Старые версии не удаляем, чтобы было понятно, какой версией получены результаты.

Файл промпта целиком уходит модели, поэтому пометки вроде «черновик» пишем здесь, а не в самом промпте. Сейчас `interviewer/v1.md` — черновик.
