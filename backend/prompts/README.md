# Промпты

Промпты хранятся отдельно от кода (п. 4.5.2 ТЗ). Каждый файл имеет версию в имени:

```
prompts/<задача>/v<номер>.md            общий вариант
prompts/<задача>/v<номер>.<модель>.md   вариант под конкретную модель (claude, gigachat, yandexgpt)
```

Задачи: `planner` (черновик плана интервью), `interviewer`, `moderation`, `pii`, `analysis`.

Старые версии не удаляем: в результатах анализа сохраняется, какой версией промпта они получены.

Файл промпта целиком уходит модели, поэтому служебные пометки (например, «черновик») пишем здесь, а не в самом промпте.
